# Flower World · 플라워 월드

[🌼 웹에서 바로 플레이하기](https://fox9star.github.io/flower/)

꽃바람 섬에서 펼쳐지는 독자적인 2D 횡스크롤 브라우저 RPG입니다. 외부 게임의 그래픽, 캐릭터, 음원, 코드를 사용하지 않았습니다. 서버 계정이나 멀티플레이 기능이 없는 싱글 플레이 게임입니다.

## 실행

Python 3가 설치된 Windows에서는 `Play-Flower-World.cmd`를 더블클릭하면 브라우저에서 게임이 열립니다. 이미 게임 서버가 실행 중이면 다시 사용합니다.

다른 환경에서는 Python 3가 설치된 상태에서 이 폴더를 열고 실행합니다.

```powershell
python -m http.server 4173 --directory docs
```

브라우저에서 http://localhost:4173 에 접속합니다. Node.js가 있으면 `npm start`도 사용할 수 있습니다. 정적 파일만으로 구성되어 별도의 빌드나 의존성 설치가 필요하지 않습니다. ES 모듈을 사용하므로 `index.html`을 파일로 직접 열지 말고 HTTP 서버로 실행하세요.

| 행동 | 키 |
| --- | --- |
| 이동 | 방향키 좌우 또는 A / D |
| 점프 · 이단 점프 | Space, 위쪽 방향키 또는 W |
| 검 공격 | Z |
| 꽃바람 스킬 | X |
| 대화 · 포털 | E |
| 회복 물약 | H |
| 가방 · 강화 · 물약 구매 | I |
| 월드맵 | M |
| 퀘스트 | Q |

모바일에서는 화면 하단의 터치 버튼으로 이동·공격·점프·스킬·상호작용을 조작합니다. 체력 물약은 게임 아래 도구 모음에서 사용할 수 있습니다.

## 모험

- 꽃바람 초원, 반딧불 숲, 달빛 유적의 세 지역을 탐험합니다.
- 첫 번째 퀘스트는 몬스터 5마리, 두 번째는 8마리, 마지막은 유적의 보스 처치입니다.
- 퀘스트 창에서 보상을 받거나 NPC 루미에게 대화하면 다음 지역이 열립니다.
- 몬스터는 재등장하며, 모든 퀘스트 완료 후에도 자유롭게 플레이할 수 있습니다.
- 무기 강화는 공격력 +8, 물약은 최대 HP의 65% 및 MP 35 회복입니다.
- 브라우저의 localStorage에 진행 상황을 자동 저장합니다. 레벨·골드·장비·퀘스트·지역을 복원하며, 다시 접속하면 지역 초입에서 시작합니다. 저장은 해당 기기·브라우저·주소에 한정됩니다.

## 파일

- `docs/index.html` — 게임 화면과 접근성 마크업
- `docs/style.css` — 반응형 레이아웃
- `docs/app.js` — 입력, 메뉴, HUD, 효과음
- `docs/engine.js` — 물리, 전투, 퀘스트, 성장, 저장
- `docs/renderer.js` — 직접 제작한 Canvas 풍경, 캐릭터, 애니메이션

`docs/` 폴더가 GitHub Pages 게시 원본입니다. `main`의 `docs/`에 변경 사항을 푸시하면 웹사이트가 자동으로 갱신됩니다.

효과음은 Web Audio로 생성합니다. 글꼴을 포함해 게임에 필요한 모든 리소스를 로컬에서 불러오므로 외부 요청 없이 시작합니다. 글꼴은 OFL 사용 조건에 따라 같이 제공됩니다.

## 검증

`npm run check`로 JavaScript 구문을 확인할 수 있습니다. 개발 시 엔진 시뮬레이션으로 전체 퀘스트 진행과 저장 복원을 확인했고, 실제 Chrome에서 키보드 조작·메뉴·저장·모바일 레이아웃을 검증했습니다.
